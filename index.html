《问剑》的开发／发行／运营主体为人生何处不青山的工作室1。本政策说明当前 Windows Demo 中与游戏数据、隐私及联系反馈有关的处理方式，以及您管理相关信息和联系开发者的途径。

01适用范围

本页适用于《问剑》Windows Demo 本身。您通过 TapTap 下载、登录平台或使用平台服务时，平台对相关信息的处理另由其隐私政策说明。本页不代替 TapTap 或其他第三方的隐私政策。

当前游戏未设置独立游戏账号注册、广告、支付或云存档功能，未接入 TapSDK。开发者没有在自研游戏功能中设置自动上传游戏存档或运行日志的功能。未来新增服务或改变信息处理方式时，将按实际情况更新政策及必要的告知、授权安排。

02本地游戏数据

  • 游戏存档：保存角色成长、灵蕴、技能、休息点和关卡进度等，用于继续游戏；存在本地备份文件。
  • 音量设置：保存主音量、音乐和音效偏好，供下次启动沿用。
  • 本地运行日志：Unity 引擎开启本地运行日志，可记录运行错误、系统或设备相关的技术信息，用于定位运行问题。请在向开发者发送日志前检查并移除无关个人信息。

游戏存档与音量设置使用 Unity 提供的应用持久化数据目录，不要求您的电脑存在特定盘符。上述保存逻辑将这些内容写入本地文件，没有自动云端同步。

03联系与反馈

您主动通过电子邮件联系开发者时，会提供发件邮箱、消息内容，以及您自行附带的截图、日志或存档。这些信息用于理解反馈、处理问题及回复您。

请不要发送身份证件、账号密码、验证码或其他与问题无关的敏感资料。发送日志或截图前，请检查并移除其中不必要的个人信息。

反馈信息仅由开发者本人查阅，用于回复、问题排查及处理。问题处理结束后，开发者将在 90 天内删除本人管理的反馈邮件及附件；需要保留的问题记录仅保留不含个人信息的内容。

邮件传输及存储还涉及您使用的邮件服务商和收件邮箱服务商。上述安排针对开发者管理的邮件及附件，不代替服务商对其系统数据的处理规则。

04第三方服务与政策网页

  • 游戏引擎 · Unity：本游戏使用 Unity 引擎。当前工程服务配置关闭 Unity Analytics、广告及崩溃报告服务。有关 Unity 服务中的信息处理说明，见Unity 玩家隐私政策。其中介绍的其他 Unity 产品或功能不代表本游戏全部启用；关闭上述服务也不等于确认引擎全部底层通信均不处理技术信息，当前发行版本尚未进行独立网络核查。
  • 发行平台 · TapTap：平台账号、客户端、下载及平台服务与游戏本地存档分开。当前游戏未集成 TapSDK；平台的信息处理见TapTap 隐私政策，不应将平台账号或实名功能视为本游戏内已接入的功能。
  • 反馈邮箱 · QQ 邮箱：公开收件地址为 1009876153@qq.com，使用腾讯提供的 QQ 邮箱服务。您主动发送反馈时，发件地址、消息内容及附件经邮件服务传输和存储。收件服务商的信息处理说明见QQ 邮箱隐私保护指引，您自己的发件服务商另有其规则。QQ 邮箱仅用于接收及回复反馈，不是嵌入游戏的登录或统计 SDK；开发者管理的反馈信息按本政策第 03、05 至 08 节处理。
  • 政策网页托管 · GitHub Pages：当您通过 GitHub Pages 访问本政策页时，GitHub 会按其说明记录访问者 IP 地址用于安全。这是网页访问的处理，不代表游戏存档上传至 GitHub。详情见GitHub Pages 托管说明及GitHub 隐私声明。

本政策页的正文代码没有表单、统计脚本、外部字体或浏览器存储操作，不读取您的游戏存档。点击邮箱链接会交由设备上的邮件应用处理，不会直接从此页发送邮件；点击第三方链接将访问对应服务。

05信息共享、转让与公开披露

开发者不会出售您主动提交的个人信息，不将其用于广告营销，也不会擅自把您的邮件、截图、日志或存档转交他人或公开发布。用于保留的问题记录仅包含不含个人信息的内容。

除第 04 节说明的邮件传输、存储等服务处理外，开发者仅在取得您针对具体事项的明确同意，或法律法规、有权机关依法提出的要求下，向其他接收方提供必要的信息。需要取得同意时，将先说明接收方、用途及信息范围，不以您发送反馈作为同意任意共享的依据。

上述规则适用于开发者管理的反馈信息。您自行公开的内容，以及发行平台、邮件服务商和网页托管商独立处理的信息，应同时查阅相应服务的隐私政策。

06数据保存与删除

本地存档与设置用于继续游戏及保留偏好，留存在您的设备上。游戏的新游戏功能会在二次确认后覆盖原进度，但不等于删除整个应用数据目录、日志或您自行保存的副本。

您可以在退出游戏后备份或删除相应本地文件；删除会造成进度或设置丢失，卸载游戏也不一定自动清除这些文件。需要查找文件位置时，可通过联系邮箱咨询。

主动反馈的信息用于回复及排查问题。问题处理结束后 90 天内，开发者删除本人管理的反馈邮件和附件；需要保留的问题记录应移除个人信息。您提出删除请求的，开发者按第 08 节处理；依法需要保留的信息，将说明原因及相应处理安排。

本地游戏文件留存在您的设备；反馈邮件还经过您选择的发件服务商和 QQ 邮箱，网页访问涉及 GitHub Pages。更换收件邮箱不代表所有环节的信息均存储在同一国家或地区，也不改变各服务商对系统记录、备份及删除的独立规则。开发者不承诺删除其无法管理的服务商全部副本。

07信息安全与事件处理

开发者本人管理反馈邮箱及附件，使用邮箱两步验证和保存反馈附件的电脑登录密码限制未经授权的访问，不对外提供账号密码或验证码，并按本政策规定控制反馈用途及保存期限。

上述措施针对开发者使用的邮箱和设备，不表示游戏存档已加密，也不表示本项目具备专业安全团队或已取得安全认证。网络服务和设备使用仍可能存在风险，请您避免在反馈中提交与问题无关的敏感信息。

如发现由开发者管理的反馈信息发生或可能发生泄露、丢失、篡改或未经授权的访问，开发者将及时停止相关不当共享或访问、排查原因并采取补救措施。在适用法律要求下，向受影响用户及有关部门说明事件情况、可能影响、已采取的措施和可供用户采取的保护措施；无法逐一通知时，按适用要求通过公开渠道说明。

08您的信息相关权利

对于您主动提交给开发者的信息，您可通过 1009876153@qq.com 提出查询、获取副本、更正、删除或停止基于您同意继续处理反馈信息的请求。停止提供反馈或提出上述请求，不影响本地游戏功能；此前已经合法进行的处理不因撤回同意而改变。

开发者将在收到请求后 15 个工作日内回复，说明处理结果、依法不能处理的原因或需进一步确认的事项。为保护您的信息，仅核对处理请求所需的必要信息，不要求您主动发送身份证件、密码或验证码。

当前游戏没有独立游戏账号，因此没有本游戏账号注销流程；本地存档和设置可按第 06 节自行管理。对反馈信息处理有疑问或投诉，也可通过联系邮箱提出。

开发者无法代替第三方平台管理其持有的数据，相关请求应向对应服务提供者提出。

09未成年人保护

未成年人如需向开发者发送反馈，请在监护人指导下进行，不要发送与反馈无关的个人或家庭信息。

当前游戏没有内置的实名认证、年龄验证或防沉迷系统，也不在游戏中设置身份证件信息提交功能。平台适龄、下载和访问规则以平台实际提供的服务为准；本政策不表示已在游戏中启用未成年人拦截或游玩时长限制。

监护人如对未成年人主动提交给开发者的信息有疑问，或希望提出查询、删除请求，可通过下方邮箱联系开发者。

10政策更新

当游戏功能、第三方服务或信息处理方式发生变化时，政策将同步更新，并标明更新及生效日期。涉及需要告知或取得同意的变化，将按实际情形在游戏或发布渠道提供相应说明。

最新政策通过本页面公开。您可以查看页面顶部的更新日期；如对版本或内容有疑问，可通过联系邮箱咨询。
